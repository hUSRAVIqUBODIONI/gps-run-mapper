# Running App

Мобильное приложение для бега на Kotlin с использованием Jetpack Compose.

## Технологии и инструменты

- **Kotlin + Jetpack Compose** — UI
- **Room** — локальная база данных
- **Foreground Service** — для отслеживания активности в фоне
- **Google Maps API** — отображение маршрутов и текущего местоположения

## Основные функции

- Запись и отображение маршрутов бега
- Отслеживание местоположения в реальном времени с помощью Foreground Service
- Сохранение данных в локальную базу Room
- Визуализация маршрута на карте Google Maps
